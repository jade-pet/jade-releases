# Jade for Mac — downloads

A cat lives on your Mac's desktop and tells you when to take a break. This repository holds the
downloads only; Jade's source is private. More at **[jadethecat.com](https://jadethecat.com)**.

Jade 让一只猫住进你的 Mac，到点叫你起来歇会儿。这个仓库只放下载文件，源代码不公开。详见
**[jadethecat.com](https://jadethecat.com/zh/)**。

## Install / 安装

- **[Download Jade.dmg](https://jadethecat.com/mac/download)**, open it and drag Jade to Applications.
  下载 Jade.dmg，打开后把 Jade 拖进「应用程序」。
- Or in Terminal / 或者在终端里：

  ```bash
  bash -c "$(curl -fsSL https://jadethecat.com/mac/install)"
  ```

- Or with Homebrew / 或者用 Homebrew：`brew install --cask misoto22/tap/jade`

Needs macOS 26 or later. 需要 macOS 26 或更高版本。

## What's here / 这里有什么

- [Releases](https://github.com/jade-the-cat/jade-releases/releases): every version's DMG, checksums
  and notes. 每个版本的 DMG、校验值和更新说明。
- `install.sh`: the script behind `jadethecat.com/mac/install`. 安装脚本。
- `INSTALL-AGENT.md`: instructions for an AI agent installing Jade, at `jadethecat.com/mac/agent`.
  给 AI agent 看的安装说明。

These files are copied here automatically with each release; changes made here are overwritten.
这些文件随每次发布自动同步，直接在这里修改会被覆盖。
